Are Harris County Drivers the Worst in Texas?

Fredy Guevara

2026-03-12

Introduction

This project studies whether Harris County, which includes Houston, has the worst drivers among a selected group of Texas counties. The counties included in this analysis are Harris, Travis, Bexar, Montgomery, Hays, Medina, Hidalgo, Hale, and Lipscomb.

The goal is not just to compare the total number of crashes, since larger counties naturally tend to have more crashes. Instead, this project compares counties using crash rates, fatal crash rates, and the proportions of crashes involving speeding, alcohol, and distracted driving.

Research Question

Does the data suggest that Harris County has the worst drivers among the selected Texas counties?

Data

The data used in this project were obtained from the Texas Department of Transportation (TxDOT) Motor Vehicle Crash Statistics database:

https://www.txdot.gov/data-maps/crash-reports-records/motor-vehicle-crash-statistics.html

The dataset was constructed by extracting county-level crash statistics for the year 2024 from several PDF reports provided on the TxDOT website. These reports included:

  • Total crashes and injuries by county
  • Speed-related crashes
  • DUI (alcohol-related) crashes
  • Distracted driving crashes
  • Fatal crashes

The counties selected for this analysis are Harris, Travis, Bexar, Montgomery, Hays, Medina, Hidalgo, Hale, and Lipscomb.

Population estimates for each county were taken for July 2024 in order to match the time frame of the crash data.

The raw data were first organized in Excel and then imported into R for cleaning, transformation, and analysis.

Creating New Variables

To compare counties fairly, several derived variables were created using the following formulas. \[ \text{Crash Rate} = \frac{\text{Total Crashes}}{\text{Population}} \times 100{,}000 \]

\[ \text{Fatal Crash Rate} = \frac{\text{Fatal Crashes}}{\text{Population}} \times 100{,}000 \]

\[ \text{Speed Percent} = \frac{\text{Speed Crashes}}{\text{Total Crashes}} \]

\[ \text{DUI Percent} = \frac{\text{DUI Crashes}}{\text{Total Crashes}} \]

\[ \text{Distracted Percent} = \frac{\text{Distracted Crashes}}{\text{Total Crashes}} \]

\[ \text{Severity Percent} = \frac{\text{Fatal Crashes + Serious Crashes}}{\text{Total Crashes}} \]

crash <- crash %>%
  mutate(
    Total_Crashes = as.numeric(gsub(",", "", Total_Crashes)),
    Population = as.numeric(gsub(",", "", Population)),
    Fatal_Crashes = as.numeric(gsub(",", "", Fatal_Crashes)),
    Speed_Crashes = as.numeric(gsub(",", "", Speed_Crashes)),
    DUI_Crashes = as.numeric(gsub(",", "", DUI_Crashes)),
    Distracted_Crashes = as.numeric(gsub(",", "", Distracted_Crashes)),
    Serious_Crashes = as.numeric(gsub(",", "", Serious_Crashes)),
    Minor_Crashes = as.numeric(gsub(",", "", Minor_Crashes))
  )

crash <- crash %>%
  mutate(
    Crash_Rate = (Total_Crashes / Population) * 100000,
    Fatal_Rate = (Fatal_Crashes / Population) * 100000,
    SpeedPercent = Speed_Crashes / Total_Crashes,
    DUIPercent = DUI_Crashes / Total_Crashes,
    DistractedPercent = Distracted_Crashes / Total_Crashes,
    SeverityPercent = (Fatal_Crashes + Serious_Crashes) / Total_Crashes
  )

Confidence Interval

To estimate the crash rate, a confidence interval is calculated using:

\[ \hat{p} = \frac{\text{Total Crashes}}{\text{Population}} \]

\[ \hat{p} \pm z \sqrt{\frac{\hat{p}(1-\hat{p})}{n}} \]

Confidence Interval for Harris County

Here, \(\hat{p}\) represents the observed crash proportion and \(n\) is the population of Harris County. The value \(z = 1.96\) corresponds to a 95% confidence level.

The results below show the estimated range for the crash rate in Harris County. z=1.96.

harris <- crash %>% filter(County == "Harris")

p_hat_harris <- harris$Total_Crashes / harris$Population
n_harris <- harris$Population
z <- 1.96
se_harris <- sqrt((p_hat_harris * (1 - p_hat_harris)) / n_harris)

lower_harris <- p_hat_harris - z * se_harris
upper_harris <- p_hat_harris + z * se_harris

lower_harris * 100000
## [1] 2288.529
upper_harris * 100000
## [1] 2314.808

New Code I made to just include all the counties confidence intervals.

ci_all <- crash %>%
  mutate(
    p_hat = Total_Crashes / Population,
    n = Population,
    z = 1.96,
    se = sqrt((p_hat * (1 - p_hat)) / n),
    Lower_CI = (p_hat - z * se) * 100000,
    Upper_CI = (p_hat + z * se) * 100000,
    Crash_Rate = p_hat * 100000
  ) %>%
  select(County, Crash_Rate, Lower_CI, Upper_CI)

Interpretation

The regression model examines how crash rates are related to speeding, DUI, and distracted driving.

The coefficients show how much the crash rate is expected to change when each factor increases, holding the others constant. Variables with smaller p-values (typically less than 0.05) are considered statistically significant predictors.

If speeding has the largest coefficient and is statistically significant, this suggests that it is the strongest contributor to higher crash rates among the counties studied. Similarly, significant DUI or distracted driving variables indicate their importance in explaining crash behavior.

The \(R^2\) value shows how much of the variation in crash rates is explained by the model. A higher value indicates a better fit.

Conclusion

This analysis compared selected Texas counties using crash rates, fatal crash rates, confidence intervals, and regression modeling.

While Harris County has the largest number of crashes, this is largely due to its large population. When adjusting for population using crash rates, Harris County may or may not rank as the highest, depending on the data.

The regression results suggest that driver behavior factors such as speeding, DUI, and distracted driving play a significant role in determining crash rates. Among these, the most influential factor can be identified based on the model coefficients and statistical significance.

Overall, the results show that determining the “worst drivers” is not simply about total crashes, but about relative risk and contributing behaviors.
